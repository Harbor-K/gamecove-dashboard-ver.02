# Fonts

## Lato (영어, 기본)
Lato 2.0 (Łukasz Dziedzic, SIL Open Font License 1.1), npm `lato-font@3.0.0`에서 복사.
Google Fonts의 Lato에는 SemiBold(600)·Medium(500)이 없어서 로컬 파일을 쓴다.

| 파일 | 굵기 | Figma |
| --- | --- | --- |
| lato-normal.woff2 | 400 | Regular |
| lato-medium.woff2 | 500 | Medium |
| lato-semibold.woff2 | 600 | SemiBold (버튼 라벨 등) |
| lato-bold.woff2 | 700 | Bold |

## Pretendard (한국어, `?lang=ko`)
Pretendard 1.3.9 (Kil Hyung-jin, SIL Open Font License 1.1), npm `pretendard`의 `dist/web/static/woff2-subset`에서 복사.
subset = 자주 쓰는 한글 2,350자 + 라틴. Lato와 같은 굵기 값으로 매핑한다.

| 파일 | 굵기 |
| --- | --- |
| pretendard-regular.woff2 | 400 |
| pretendard-medium.woff2 | 500 |
| pretendard-semibold.woff2 | 600 |
| pretendard-bold.woff2 | 700 |
